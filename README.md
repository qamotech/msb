# 🚌🔬 Magic School Bus Classroom

**Science classroom collection with teacher and student dashboards, worksheet generators, lesson hubs, electricity activities, and printable lab resources.**

🏷️ Maintained in [qamotech/msb](https://github.com/qamotech/msb) · 🌐 Public repository

## ✨ What is here

- 🎓 Teacher dashboard, student portal, roster, and grading interfaces.
- 📝 Worksheet, quiz, and science-packet generators.
- ⚡ Electricity activities, experiment pages, and video references.
- 📚 Multiple classroom variants plus Word lab guides and local visual assets.

## 🧭 Try the project

Open index.html, choose a science station, preview a worksheet, and try the print workflow before using materials with a class. Review the individual HTML pages for alternate lesson formats.

## 🚀 Local setup

```sh
git clone https://github.com/qamotech/msb.git
cd msb
```

Use a current browser. Serve the repository root to preserve relative assets and a stable browser origin:

```sh
python -m http.server 8000
```

Open `http://localhost:8000/index.html`. Keep related assets beside the entry file. No npm setup is declared in the inspected repository.
