🤖 Agent API for Codex / automation

Your AI agent can drive this app programmatically via the console or a relay file:
Console API (agent runs this in DevTools) 
// Submit a task and await the result:
const result = await window.QuotaBridge.submit(
  "Summarize: "
);
console.log(result);

// Batch:
const answers = await window.QuotaBridge.submitMany([
  "What is X?", "Explain Y in 2 sentences"
]);

// Agent checks quota stats:
window.QuotaBridge.stats()
