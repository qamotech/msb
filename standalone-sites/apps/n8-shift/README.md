# N8 SHIFT: Transform Protocol

Open [launch.html](launch.html). Original compatibility URL: `standalone-sites/n8-shift.html`.

A remix of N8 Strike and Mecha Strike into a new game: a neon synthwave runner where you shift the mech between RACER, JET and TITAN to slide under lasers, fly over pits and smash walls. It includes a Warden boss, the Black Market garage, missions, a daily circuit and local records.

The source file here and its original path are NTFS hard links to the same bytes. In-place edits update both; editors that replace a file atomically can break that relationship. Check `os.path.samefile` after editing or refresh the link deliberately. Do not open the source through the new folder URL: relative resources and file-mode browser storage belong to the original URL.

External hosts found in source: fonts.googleapis.com, fonts.gstatic.com (fonts only; system fonts are used offline).

Browser persistence: localStorage (`n8shift.save.v1`).
