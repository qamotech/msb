    N8Sheetz Feature Guide & Reference ✕

    📊 Core Functionality

    N8Sheetz is an advanced virtualized spreadsheet engine. It supports infinite scrolling, frozen rows and columns, and basic state management. Double-click any cell to enter edit mode, and press Enter to save your changes.

    🛠️ Toolbar Legend

    Clipboard Operations: Copy/Paste values or formats.
    Theme Cycler: Toggle between Light, Dark, Aurora, Hacker, etc.
    AI Predict: Generates data predictions based on selected ranges.
    Sync Database: Connects your active sheet to an external SQL database.
    Macro Record: Records your keystrokes to automate repetitive tasks.
    3D Chart Engine: Renders WebGL charts based on selected data.
