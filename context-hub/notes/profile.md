- **Builds:** single-file HTML apps with no build step: games, productivity tools, AI tooling, kids' education, business sites. Vanilla JS + CSS custom properties, occasional CDN libs. Deploys statically (GitHub Pages).

## How to work
- Execute broad directives ("analyze all", "tackle all") autonomously. Don't ask to narrow scope.

- Never delete HTML files. Before pushing, verify the push is new compared with the remote.
